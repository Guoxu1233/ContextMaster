# ContextMaster Project Page

Static project page for ContextMaster. No build step or JavaScript dependency is required.

## Local preview

```bash
python3 -m http.server 8000 --directory .
```

Open `http://localhost:8000`.

## Publish with GitHub Pages

1. Push the contents of this directory to a GitHub repository.
2. In **Settings → Pages**, select **Deploy from a branch**.
3. Select the target branch and the repository root (`/`).

The page uses relative asset paths and can be published from either a user site or a project repository.
